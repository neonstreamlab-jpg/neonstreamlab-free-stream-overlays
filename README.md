# NeonStreamLab Free Stream Overlays

A curated collection of free animated stream overlay samples for Twitch, YouTube, and Kick. The assets are designed for OBS Studio, Streamlabs, and StreamElements.

## Download

Browse and download the current free collection from the official page:

**https://neonstreamlab.com/free**

Each free pack has its own download flow and preview. The available themes and included assets may change as the collection is updated.

## What you can expect

- Animated stream screens and matching visual elements
- Assets prepared for common streaming workflows
- Compatibility with Twitch, YouTube, and Kick
- Support for OBS Studio, Streamlabs, and StreamElements
- A way to test NeonStreamLab's visual quality before choosing a complete pack

## Quick setup

1. Download a free pack from the official NeonStreamLab page.
2. Extract the downloaded archive.
3. In OBS Studio, add animated files as **Media Sources** and static files as **Image Sources**.
4. Enable looping for animated screens when appropriate.
5. Position and resize each element to match your canvas.
